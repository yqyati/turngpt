# Graduation project operation rules

- Do not invoke `rlaunch` or `rjob`, including resource queries or management.
- Do not use alternate tools, APIs, remote connections, or delegation to start or schedule cluster/GPU work.
- GPU training, evaluation, and latency experiments are started manually by the user. Requests to test or continue authorize code preparation, CPU checks, and analysis of completed results.
- Keep the original sibling `kth` directory unchanged. This directory is an independent curated copy.
